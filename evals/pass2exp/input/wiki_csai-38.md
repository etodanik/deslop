**Web search** is the process of looking for information on the World Wide Web, usually by entering a query into a **web search engine** like Google, Bing, DuckDuckGo, or Baidu. The engine returns a ranked list of web pages, images, videos, and other resources relevant to the query.

**How web search works**

1. **Crawling:** Automated programs called *web crawlers* (or spiders or bots) follow links from page to page across the web, discovering and fetching content.
2. **Indexing:** The content of the pages is analyzed and stored in a huge database called an *index*. The index records which words and features appear on each page, allowing fast lookup, much like the index at the back of a book. (A common data structure is the *inverted index*.)
3. **Query processing:** When a user enters a query, the engine interprets it, handling things like spelling errors, synonyms, and the likely intent behind the words.
4. **Ranking:** The engine scores the matching pages and sorts them. Ranking uses many signals, such as keyword relevance, link structure (e.g., Google's original **PageRank** algorithm, which treats links as votes of importance), content quality, freshness, user location, personalization, page speed, and mobile-friendliness. Modern engines use machine learning extensively.
5. **Presentation:** Results are displayed on a results page, often with snippets, ads, featured answers, maps, and images.

**Types of web search**

- General web search
- Vertical search (images, news, video, shopping, academic)
- Local search
- Voice and conversational search
- Semantic and AI-driven search

**Key topics**

- **Search engine optimization (SEO):** Techniques for improving a site's visibility in search results.
- **Paid search advertising:** Advertisers bid to place ads alongside results, which is the main revenue source for many engines.
- **Information retrieval:** The academic field that underpins search, studying how to find relevant documents in large collections.
- **Deep web:** Content not indexed by standard search engines, such as pages behind logins or paywalls.
- **Privacy and bias:** Concerns about tracking, personalization, filter bubbles, and the influence of ranking on what people see.

**Evolution**

Early web search relied on directories and simple keyword matching (e.g., Archie, AltaVista, Yahoo). Google's link analysis dramatically improved relevance in the late 1990s. More recently, advances in natural language processing and large language models have enabled more conversational and generative search experiences.
