**Web search** is looking for information on the World Wide Web, usually by typing a query into a web search engine like Google, Bing, DuckDuckGo or Baidu. The engine returns a ranked list of web pages, images, videos and other resources that match the query.

It works in five steps.

1. **Crawling:** Automated programs called web crawlers (or spiders or bots) follow links from page to page across the web and fetch the content they find.
2. **Indexing:** The pages are analyzed and stored in a huge database called an *index*, which records which words and features appear on each page. That makes lookup fast, much like the index at the back of a book. (A common data structure is the *inverted index*.)
3. **Query processing:** When a user enters a query, the engine interprets it, handling spelling errors and synonyms and guessing the intent behind the words.
4. **Ranking:** The engine scores the matching pages and sorts them. It weighs keyword relevance, link structure, content quality, freshness, user location, personalization, page speed and mobile-friendliness. One example is Google's original **PageRank** algorithm, which treats links as votes of importance. Current engines rely heavily on machine learning.
5. **Presentation:** Results appear on a results page, often with snippets, ads, featured answers, maps and images.

Search comes in several kinds: general web search, vertical search (images, news, video, shopping, academic), local search, voice and conversational search, and semantic and AI-driven search.

Related topics:

- **Search engine optimization (SEO):** Techniques for improving a site's visibility in search results.
- **Paid search advertising:** Advertisers bid to place ads next to results, which is the main revenue source for many engines.
- **Information retrieval:** The academic field behind search, which studies how to find relevant documents in large collections.
- **Deep web:** Content that standard search engines don't index, such as pages behind logins or paywalls.
- **Privacy and bias:** Concerns about tracking, personalization, filter bubbles, and how ranking shapes what people see.

Early web search relied on directories and simple keyword matching (e.g., Archie, AltaVista, Yahoo). Google's link analysis greatly improved relevance in the late 1990s. More recently, natural language processing and large language models have made conversational and generative search possible.
